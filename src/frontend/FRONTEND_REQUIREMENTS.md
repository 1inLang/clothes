# 织序前端需求基线（Vue 版）

## 1. 技术基线

- 前端调整为独立 Vue 3 SPA，不再使用 Thymeleaf、HTMX、Alpine.js。
- 工程采用 Vue 3、TypeScript、Vite、Vue Router、Axios。
- 开发环境通过 Vite 将 `/api` 代理到 `http://localhost:8123`。
- Sa-Token 会话优先使用 Cookie；如后端返回 Token，前端通过 `satoken` 请求头携带。

## 2. 现有后端接口边界

| 页面能力 | 接口 | 实现状态 |
| --- | --- | --- |
| 用户登录 | `POST /api/user/login` | 已接入 |
| 当前用户 | `GET /api/user/get/login` | 已接入 |
| 用户退出 | `POST /api/user/logout` | 已接入 |
| 用户注册 | `POST /api/user/register` | 已接入登录首页 |
| 管理员新增用户 | `POST /api/user/add` | 已接入 |
| 用户分页查询 | `POST /api/user/list/page/vo` | 已接入 |
| 用户信息更新 | `POST /api/user/update` | 已接入 |
| 用户删除 | `POST /api/user/delete` | 已接入 |
| 根据 ID 查询用户 | `GET /api/user/get/vo` | 已接入 |
| 项目、任务、审核、通知、日志 | 暂无后端接口 | 页面原型使用演示数据，服务层预留替换点 |

## 3. 页面与导航

- 登录与注册：账号密码登录、普通账号注册、Sa-Token 会话、演示入口。
- 工作台：我的待办、待审核、即将逾期、项目进度和最近动态。
- 项目：列表筛选、状态与进度、项目详情入口。
- 任务：看板/列表、负责人、审核人、截止时间和版本状态。
- 审核：待审核队列、设计稿预览、审核通过和退回意见。
- 用户管理：真实分页查询、管理员新增、编辑和删除用户。
- 角色权限：角色说明和权限码矩阵。
- 通知与审计：站内通知、关键操作日志与筛选。

## 4. 权限与交互规则

- 未登录访问业务路由跳转登录页。
- 前端依据 `userRole` 控制导航和操作入口，但后端必须继续执行 Sa-Token 鉴权。
- 危险操作需要二次确认；退回审核时意见必填。
- 页面适配 1366×768 桌面环境，并支持常见平板宽度。
- 列表、筛选、分页和状态标签使用统一视觉语言。

## 5. 后端待补接口

要将演示页面变为完整业务系统，后端还需要项目、成员、任务、设计稿版本、审核记录、通知、角色权限和审计日志的 CRUD/状态流转接口，并返回符合统一 `BaseResponse<T>` 格式的数据。
